# 6차 분석: 고난도 노이즈 및 다국어/단위 대응

## 현상 분석 (AS-IS)

### 1. Sample 08 (English)
- **라벨 미인식**: "Date", "Truck No", "Gross Weight" 등의 영문 라벨을 인식하지 못함.
- **날짜 포맷**: `2025-Oct-20` 파싱 불가.
- **Prefix 값 포함**: `issuer` 추출 시 "Supplier :"와 같은 라벨성 텍스트가 값에 포함됨.

### 2. Sample 09 (Unit Confusion)
- **소수점 단위 미처리**: `24.50 ton`을 `kg` 단위로 환산하지 못하거나 정수부만 취함. (예: `2450` or `24`)
- **차량번호 분리**: "경기 99 바 1234"가 띄어쓰기로 인해 파편화되어 "1234"만 추출됨.
- **날짜 포맷**: `YY.MM.DD` (`25.12.25`) 처리 불가.

### 3. Sample 10 (Extreme Noise)
- **중량 오인식**: `ticket_id`나 `vehicle_num` (8713)을 중량으로 오인식. 실제 중량 리스트는 라벨과 위치가 어긋남.
- **Company/Phone 혼재**: "거래처:" 라벨의 값으로 "전화번호"를 가져오거나, Issuer와 전화번호가 병합됨.
- **Ticket ID 미추출**: `No.` 라벨 인식 실패 또는 값 추출 실패.

## 개선 계획 (TO-BE)

### 1. SmartLabelDetector 설정 강화
- **영문 라벨 추가**: 
  - Date: `Date`
  - Vehicle: `Truck`, `Lorry`, `No`
  - Weight: `Gross`, `Tare`, `Net`, `Weight`
  - Company: `Supplier`, `Customer`
- **Ticket ID 라벨 보강**: `No.`, `Ticket`, `Slip`

### 2. Extractor 로직 개선

#### A. WeightExtractor
- **단위 환산 로직**: 값 주변(오른쪽)에 `ton`, `t`가 있는지 확인하여 `x1000` 적용.
- **소수점 처리**: 값이 소수점(예: `24.50`)인 경우 정수화 로직 수정.
- **이상치 제거**: 중량 후보 중 차량번호나 ID로 의심되는 값(예: 4자리 수, 라벨이 'No'인 것 근처) 제외.

#### B. VehicleExtractor
- **Spaced Text Merging**: 차량번호 패턴(`지역+숫자+한글+숫자`)이 공백으로 나뉘어 있을 경우 이를 병합하여 인식하는 로직 추가. (SpatialExtractor의 기능 활용 또는 VehicleExtractor 전용 병합)

#### C. DateExtractor
- **포맷 확장**: 
  - `YY.MM.DD` (예: 25.12.25)
  - `YYYY-Mon-DD` (예: 2025-Oct-20) - 영문 월 매핑 테이블 필요.

#### D. Company/IssuerExtractor
- **Prefix 제거**: "Supplier :", "Customer :" 제거.
- **전화번호 분리**: 추출된 회사명에 전화번호 패턴이 포함된 경우 분리/제거.

5. `IssuerExtractor` 정제 로직 강화 (전화번호 제거, Prefix 제거).
