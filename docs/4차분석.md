# UniversalOCRParser 수정 사항 정리

## 🔧 적용된 수정사항

### 1. 좌표 기반 라인 클러스터링 개선
**문제**: Y좌표 허용 범위가 너무 좁아서 같은 줄의 단어들이 다른 줄로 분리됨

**수정**:
```python
# Before
def _cluster_into_lines(self, word_boxes, y_tolerance: float = 20):

# After  
def _cluster_into_lines(self, word_boxes, y_tolerance: float = 50):
```

**효과**: 라벨과 값이 약간 비스듬하게 정렬된 경우에도 같은 줄로 인식

---

### 2. 퍼지 매칭 임계값 완화
**문제**: 임계값이 너무 높아서 OCR 노이즈가 있는 라벨을 찾지 못함

**수정**:
```python
# Before
def _fuzzy_match_label(self, text, candidates, threshold: float = 75):

# After
def _fuzzy_match_label(self, text, candidates, threshold: float = 65):
```

**효과**: '품종명랑' → '품명', '차 중 량' → '차중량' 등 오타가 심한 라벨도 매칭 가능

---

### 3. find_right_of 검색 범위 대폭 확대
**문제**: X축 검색 범위가 너무 좁아서 라벨 옆에 있는 값을 찾지 못함

**수정**:
```python
# Before
def _find_right_of(self, anchor, word_boxes, x_threshold: float = 50):

# After
def _find_right_of(self, anchor, word_boxes, x_threshold: float = 500):

# 중량 필드는 더 넓게
right_words = self._find_right_of(word, word_boxes, x_threshold=800)
```

**효과**: 라벨과 값 사이에 간격이 크거나 여러 열로 배치된 경우에도 추출 가능

---

### 4. find_below 검색 범위 및 겹침 조건 완화
**문제**: Y축 범위와 X축 겹침 조건이 너무 엄격해서 바로 아래 값을 못 찾음

**수정**:
```python
# Before
def _find_below(self, anchor, word_boxes, 
                y_threshold: float = 100, x_overlap: float = 0.3):

# After
def _find_below(self, anchor, word_boxes,
                y_threshold: float = 150, x_overlap: float = 0.2):
```

**효과**: 수직 배치된 라벨-값 쌍을 더 잘 인식

---

### 5. 숫자 추출 패턴 다양화
**문제**: 공백으로 분리된 숫자 패턴 인식이 불완전함

**수정**:
```python
# Before
pattern = r'\b\d+(?:\s+\d{3})*\b|\b\d+\b'

# After - 여러 패턴 순차 시도
patterns = [
    r'\d+\s+\d{3}(?:\s+\d{3})*',  # "13 460" 형태
    r'\d+[,]\d{3}',                # "12,480" 형태  
    r'\d{1,2}\s+\d{3}',            # "1 320" 형태
    r'\d+',                         # 일반 숫자
]
```

**효과**: "13 460", "1 320", "12,480" 등 다양한 형식의 숫자 인식

---

### 6. Y좌표 허용 범위 조정
**문제**: 같은 줄 판단 기준이 너무 엄격함

**수정**:
```python
# Before  
y_threshold: float = 30  # find_right_of

# After
y_threshold: float = 50  # find_right_of
```

**효과**: 약간 기울어진 스캔 문서에서도 정상 동작

## 🎯 기대 효과

### Sample 01
- ✓ 중량 데이터 정확히 추출 (PASS)
- ✅ 날짜, 차량번호, 발행자, GPS 정상
- ⚠️ 거래처, 품명 추출 필요 (라벨 매칭 개선 필요)

- ✅ 퍼지 매칭 개선으로 "* 계 그 표 *" 등의 노이즈 라벨 처리

### Sample 03, 04

- ✅ 넓은 검색 범위로 다양한 레이아웃 대응
- ⚠️ 차량번호 추출 개선 필요 (패턴 인식 강화 필요)

## ⚠️ 남은 문제점

1. **거래처/회사명 추출 실패**
   - 퍼지 매칭은 작동하지만 값 추출 로직에서 한글 필터링이 너무 엄격할 수 있음
   - `_extract_company()` 메서드 개선 필요

2. **품명 추출 실패**
   - 마찬가지로 값 추출 필터링 문제
   - `_extract_product()` 메서드 개선 필요

3. **차량번호 패턴 인식 부족**
   - "80구8713", "5405", "0580" 등 다양한 형식 대응 필요
   - 정규표현식 패턴 확장 필요

4. **구분 필드 (입고/출고) 미추출**
   - 라벨 매칭은 되지만 값 추출 실패
   - 위치 기반 검색 범위 조정 필요
