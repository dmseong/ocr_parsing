## 수정 필요 사항

### 1. 날짜 추출 개선 (우선순위: 높음)
**문제**: Sample 04에서 2025-02-01이 2025-12-01로 추출됨

**원인 조사 필요**:
- OCR 데이터 확인
- 날짜 패턴 매칭 로직 검토
- 여러 날짜 후보 중 잘못된 것 선택

**수정 방향**:
- OCR 데이터에서 날짜 위치 확인
- 라벨 근처 날짜 우선 선택

### 2. 구분 필드 오추출 방지 (우선순위: 높음)
**문제**: Sample 04에 구분 값이 없는데 "입고"로 추출됨

**원인**:
- 패턴 기반 추출이 모든 word box를 스캔하여 "입고" 발견
- 실제로는 다른 샘플의 텍스트이거나 잘못된 위치

**수정 방향**:
- 라벨 기반 추출 우선 시도
- 패턴 기반은 라벨을 찾았으나 값이 없을 때만 사용

### 3. Sample 01 거래처 추출 (우선순위: 중간)
**문제**: "거 래 처: 곰욕환경폐기물" 구조에서 값 추출 실패

**원인**:
- 3단어 라벨 조합은 작동하나 오른쪽 값 검출 문제
- `_find_right_of` 로직 또는 위치 판단 문제

**수정 방향**:
